## 2026-10-16 - [Tree Growing Animation Profiling]
**Learning:** In `birthday.js`, canvas rendering performance heavily relies on drawing hundreds of elements (like tree branches) during each `requestAnimationFrame` loop. Recomputing static geometry, such as `quad` curves and linear interpolation (`lerp`) widths, at every frame causes severe redundant CPU overhead, especially since once a branch segment reaches its final form, it never changes.
**Action:** When a branch is initially computed via `addBranch`, calculate its final segment geometry (`quad(b, tt)` points and `lerp` widths) once, and cache them. Then during `drawBranches`, check if the segment is fully grown (`e >= i / steps`), and if so, fetch it directly from the cache to vastly reduce math overhead during runtime animation loops.
